┌────────────────────────────────────────────────────────────────┐
│  DEVELOPMENT (Your Local Machine)                              │
└────────────────────────────────────────────────────────────────┘

  📦 INITIALIZE (One-time)
  ┌──────────────────────────────────────────────────────────────┐
  │ dotnet user-secrets init                                     │
  └──────────────────────────────────────────────────────────────┘

  ➕ ADD SECRET
  ┌──────────────────────────────────────────────────────────────┐
  │ dotnet user-secrets set "Email:Smtp:Password" "my_pass"      │
  │ dotnet user-secrets set "Jwt:Key" "my_jwt_secret"            │
  └──────────────────────────────────────────────────────────────┘

  📋 VIEW ALL SECRETS
  ┌──────────────────────────────────────────────────────────────┐
  │ dotnet user-secrets list                                     │
  └──────────────────────────────────────────────────────────────┘

  ❌ REMOVE SECRET
  ┌──────────────────────────────────────────────────────────────┐
  │ dotnet user-secrets remove "Email:Smtp:Password"             │
  └──────────────────────────────────────────────────────────────┘

  🗑️  CLEAR ALL
  ┌──────────────────────────────────────────────────────────────┐
  │ dotnet user-secrets clear                                    │
  └──────────────────────────────────────────────────────────────┘

┌────────────────────────────────────────────────────────────────┐
│  PRODUCTION (Server/Docker)                                    │
└────────────────────────────────────────────────────────────────┘

  🌍 ENVIRONMENT VARIABLES
  
  Linux/macOS:
  ┌──────────────────────────────────────────────────────────────┐
  │ export Email__Smtp__Password="prod_password"                 │
  │ export Jwt__Key="prod_jwt_key"                               │
  └──────────────────────────────────────────────────────────────┘
  
  Windows PowerShell:
  ┌──────────────────────────────────────────────────────────────┐
  │ $env:Email__Smtp__Password="prod_password"                   │
  │ $env:Jwt__Key="prod_jwt_key"                                 │
  └──────────────────────────────────────────────────────────────┘

  🐳 DOCKER
  ┌──────────────────────────────────────────────────────────────┐
  │ docker run --env-file .env.production monitoring-gs:latest   │
  └──────────────────────────────────────────────────────────────┘

┌────────────────────────────────────────────────────────────────┐
│  REQUIRED SECRETS FOR THIS PROJECT                             │
└────────────────────────────────────────────────────────────────┘

  ✅ Jwt:Key
     - JWT secret key (minimum 32 characters)
  
  ✅ Email:Smtp:Password
     - Email account password or app password
  
  ✅ ConnectionStrings:DefaultConnection
     - Database connection string with password

┌────────────────────────────────────────────────────────────────┐
│  COMMON TASKS                                                  │
└────────────────────────────────────────────────────────────────┘

  📧 Setup Gmail
  ┌──────────────────────────────────────────────────────────────┐
  │ 1. Enable 2FA in Google Account                              │
  │ 2. Generate App Password                                     │
  │ 3. dotnet user-secrets set "Email:Smtp:Password" "xxxx"      │
  │ 4. dotnet user-secrets set "Email:Smtp:Host" "smtp.gmail.com"│
  └──────────────────────────────────────────────────────────────┘

  🔑 Generate Strong JWT Key
  ┌──────────────────────────────────────────────────────────────┐
  │ openssl rand -base64 32                                      │
  │ dotnet user-secrets set "Jwt:Key" "$(openssl rand -base64 32)"│
  └──────────────────────────────────────────────────────────────┘

  🔍 Verify Configuration
  ┌──────────────────────────────────────────────────────────────┐
  │ dotnet user-secrets list                                     │
  │ dotnet run                                                   │
  └──────────────────────────────────────────────────────────────┘

┌────────────────────────────────────────────────────────────────┐
│  ⚠️  IMPORTANT NOTES                                          │
└────────────────────────────────────────────────────────────────┘

  ❌ NEVER commit appsettings.Development.json
  ❌ NEVER commit .env files
  ❌ NEVER share secrets via email/chat
  ❌ NEVER log sensitive data
  ✅ ALWAYS use placeholders in appsettings.json
  ✅ ALWAYS rotate secrets regularly
  ✅ ALWAYS use strong, unique passwords

┌────────────────────────────────────────────────────────────────┐
│  🆘 TROUBLESHOOTING                                           │
└────────────────────────────────────────────────────────────────┘

  ❓ Secrets not loading?
  ┌──────────────────────────────────────────────────────────────┐
  │ • Check UserSecretsId in .csproj                             │
  │ • Verify secrets file exists:                                │
  │   macOS: ~/.microsoft/usersecrets/*/secrets.json             │
  │   Windows: %APPDATA%\Microsoft\UserSecrets\*\secrets.json    │
  │ • Restart application                                        │
  └──────────────────────────────────────────────────────────────┘

  ❓ SMTP not working?
  ┌──────────────────────────────────────────────────────────────┐
  │ • Verify password is correct                                 │
  │ • Check firewall/antivirus                                   │
  │ • For Gmail: Use App Password, not regular password          │
  │ • Test connection: telnet smtp.gmail.com 587                 │
  └──────────────────────────────────────────────────────────────┘
